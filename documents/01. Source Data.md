# 01. Source Data


## 1. SupportBot Overview

SupportBot is an AI agent introduced to help clinic staff with appointment and billing questions.

Its documented responsibilities are to:

- Answer appointment and billing status questions.
- Create support tickets.
- Draft responses for human approval.
  

### Identity Details

| Identity Attribute   | Details                                          |
| :------------------- | :----------------------------------------------- |
| **Identity**         | `svc-supportbot`                                 |
| **Account type**     | Service account                                  |
| **Authentication**   | API token                                        |
| **Created**          | 14 months ago by a contractor who has since left |
| **Assigned owner**   | Blank                                            |
| **Token expiration** | None                                             |
| **Token rotation**   | Never rotated                                    |
| **Environments**     | Production and staging share the same token      |
